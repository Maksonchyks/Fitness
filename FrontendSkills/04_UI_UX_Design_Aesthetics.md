# UI/UX та Дизайн Сучасних Веб-Додатків

У сучасному вебі мало просто зробити функціональний додаток — він має виглядати сучасно, преміально та бути зручним для користувача.

## 1. Сучасні Стилі та Тренди
- **Glassmorphism (Ефект скла):** Використання напівпрозорих фонів з ефектом розмиття (backdrop-filter: blur) та світлими рамками. Це додає інтерфейсу глибини та преміальності.
- **Dark Mode (Темна тема):** Використання глибоких темних кольорів (наприклад, синьо-чорні або сірі відтінки `slate` або `zinc`) замість чистого чорного (`#000000`). Це знижує навантаження на очі та виглядає стильно.
- **Gradients (Градієнти):** Плавні переходи між яскравими та глибокими кольорами (наприклад, від фіолетового до рожевого, або від неоново-синього до смарагдового).
- **Мінімалізм:** Більше "білого простору" (whitespace), відсутність зайвих ліній та рамок.

## 2. Типографіка
Шрифти відіграють критичну роль у сприйнятті дизайну.
- **Шрифти без засічок (Sans-serif):** Інтерфейсні шрифти, такі як `Inter`, `Roboto`, `Outfit`, або `Poppins`. Вони читабельні на будь-яких екранах.
- **Ієрархія:** Використовуйте чітку різницю у розмірах (font-size) та жирності (font-weight). Заголовки мають виділятися, а другорядний текст (наприклад, дати або підказки) має бути сірим/приглушеним (muted text).

## 3. Кольорова Палітра (Color Palette)
- **Primary Color:** Основний колір бренду (наприклад, неоновий фіолетовий або яскраво-синій), який використовується для головних кнопок (Call to Action) та важливих акцентів.
- **Background Colors:** Багаторівневі фонові кольори. Наприклад, `bg-darker` для фону всієї сторінки, і `bg-dark` для окремих карток на цьому фоні.
- **Semantic Colors:** Червоний для помилок (Error/Danger), зелений для успішних дій (Success), жовтий для попереджень (Warning).

## 4. Мікроанімації та Інтерактивність
Інтерфейс має відчуватися "живим" і реагувати на дії користувача.
- **Hover-ефекти:** Зміна кольору, легке збільшення (`transform: scale(1.05)`) або поява тіні при наведенні мишки на кнопку чи картку.
- **Плавні переходи (Transitions):** Усі зміни стану (hover, focus, active) мають супроводжуватися плавними анімаціями (наприклад, `transition: all 0.3s ease`).
- **Loading-стани:** Використання спінерів (`Loader2` з `lucide-react`) та скелетонів (Skeleton screens), щоб показати користувачу, що дані завантажуються.

## 5. Компоненти Дизайну
- **Кнопки:** Мають бути достатньо великими (min-height 40-44px для зручного натискання на мобільних), з округленими кутами (border-radius: 8px або повністю круглі).
- **Іконки:** Використання мінімалістичних векторних іконок (наприклад, бібліотека `lucide-react`). Іконки допомагають швидко зчитати призначення кнопки або поля.
- **Тіні (Box Shadows):** Багаторівневі м'які тіні створюють відчуття об'єму. Сучасні тіні зазвичай мають великий радіус розмиття та низьку прозорість.
