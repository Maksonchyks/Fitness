# Premium UI/UX Design System 2026 (Fitness Edition)

Цей документ є головним інструктажем для створення інтерфейсу FitnessApp. Кожен компонент повинен відповідати цим стандартам естетики та функціональності.

## 1. Візуальна мова (Aesthetics)
- **Колірна палітра**: Використовувати глибокі темні відтінки (#0A0A0A, #121212) з акцентними неоновими або пастельними градієнтами (наприклад, Electric Lime для енергії або Deep Purple для фокусу).
- **Скляний ефект (Glassmorphism)**: Картки та модальні вікна повинні мати `backdrop-filter: blur(12px)` та напівпрозорий бордюр (`rgba(255, 255, 255, 0.1)`).
- **Текстури**: Додавати ледь помітний ефект зернистості (Film Grain) на фони для створення відчуття "преміальності" та глибини.
- **Bento Grids**: Дашборди структурувати у вигляді модульних сіток Bento, де кожен блок має закруглені кути (`border-radius: 24px`).

## 2. Типографіка
- **Шрифти**: Використовувати сучасні гротески (Inter, Montserrat) або акцидентні шрифти для заголовків (Outfit, Syne).
- **Kinetic Typography**: Великі заголовки повинні мати плавні вхідні анімації або градієнтні переливи.

## 3. Мікровзаємодії та Анімації
- **Принцип**: Анімація повинна бути функціональною, а не просто декоративною.
- **Feedback**: Кожне натискання кнопки повинно мати тактильний візуальний відгук (масштабування `scale(0.98)`, зміна інтенсивності світіння).
- **Lottie анімації**: Для успішного завершення тренування або досягнення цілі використовувати плавні векторні анімації.

## 4. Calm UX (Користувацький досвід)
- **Мінімалізм**: Прибирати все зайве під час активного тренування. Тільки найважливіші показники.
- **Порожні стани (Empty States)**: Замість порожнього екрану — надихаючі ілюстрації або цитати.
- **Accessibility**: Контрастність тексту повинна відповідати стандартам WCAG, навіть у темному режимі.

## 5. Технічні вимоги до коду UI
- **CSS Variables**: Всі кольори та відступи повинні бути винесені у змінні (`--accent-color`, `--card-blur`).
- **Responsive**: Mobile-first дизайн. На великих екранах використовувати складніші сітки (Bento), на малих — вертикальний стек з горизонтальними каруселями.
- **Performance**: Використовувати `will-change` для складних анімацій, щоб уникнути лагів на слабких пристроях.
