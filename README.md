# 🏋️‍♂️ FitnessApp - Microservices Ecosystem

Сучасна екосистема для фітнесу та здоров'я, побудована на мікросервісній архітектурі з використанням **.NET 8**, **React (Vite)** та **PostgreSQL**. Проєкт поєднує в собі потужний бекенд, орієнтований на масштабованість, та преміальний UI/UX дизайн.

---

## 🏗️ Архітектура та Технології

Проєкт реалізований за принципами **Clean Architecture** та **Domain-Driven Design (DDD)**. Взаємодія між сервісами відбувається через **RabbitMQ** (Event-Driven), а реальний час забезпечується через **SignalR**.

### Стек технологій:
- **Backend**: .NET 8 (C#), Entity Framework Core, MediatR (CQRS), MassTransit (RabbitMQ), SignalR, Npgsql.
- **Frontend**: React 18, Vite, TypeScript, Lucide Icons, Vanilla CSS (Premium Aesthetics).
- **Infrastructure**: Docker, Docker Compose, PostgreSQL, Redis.

---

## 🧩 Опис мікросервісів та Функціонал

### 🔐 1. Identity Service (Сервіс Ідентифікації)
Ядро безпеки всієї системи. Відповідає за автентифікацію та авторизацію.
- **Автентифікація**: Безпечний вхід та реєстрація за допомогою JWT (JSON Web Tokens).
- **Управління ролями**: Гнучка система ролей (Користувач, Тренер, Адміністратор).
- **Профілі користувачів**: Зберігання персональних даних, цілей фітнесу та біометрії.
- **Статус Active/Inactive**: Можливість деактивації акаунтів та моніторинг активності.

### 💬 2. Communication Service (Сервіс Комунікацій)
Забезпечує соціальну взаємодію та систему сповіщень.
- **Real-time Чати**: Миттєвий обмін повідомленнями між користувачами та тренерами через SignalR.
- **Система сповіщень**: Автоматичні нагадування про тренування та харчування.
- **Гнучкі налаштування**: Користувач може сам обирати час та типи сповіщень, які хоче отримувати.
- **Background Reminders**: Фонова служба, яка кожну хвилину перевіряє розклади та розсилає "пуші".
- **Presence Tracking**: Відображення статусу користувача в мережі (Online/Offline).

### 🏋️‍♀️ 3. Workout Service (Сервіс Тренувань)
Професійний інструмент для планування фізичної активності.
- **Генерація програм**: Автоматичне створення тренувальних планів на основі цілей (Bodybuilding, Powerlifting, Weight Loss).
- **Трекінг сесій**: Запис кожного тренування з деталізацією вправ, підходів та ваги.
- **Історія прогресу**: Детальний перегляд минулих тренувань для аналізу росту показників.
- **Динамічні вправи**: База вправ з можливістю додавання нових типів активності.

### 🍎 4. Nutrition Service (Сервіс Харчування)
Повний контроль за дієтою та нутрієнтами.
- **Логування їжі**: Запис спожитих продуктів з розбивкою по калоріях та БЖВ (білки, жири, вуглеводи).
- **Щоденні цілі**: Встановлення та моніторинг виконання денної норми калорій.
- **Трекінг ваги**: Журнал змін маси тіла з візуалізацією прогресу.
- **Шаблони харчування**: Створення черги планів харчування для автоматизації раціону на тиждень.

## 🚀 Як запустити проєкт?

Весь проєкт контейнеризований, що дозволяє запустити його однією командою:

1. Переконайтеся, що у вас встановлено **Docker** та **Docker Compose**.
2. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/your-repo/FitnessApp.git
   ```
3. Запустіть інфраструктуру та сервіси:
   ```bash
   docker-compose up -d --build
   ```
4. Відкрийте фронтенд (за замовчуванням: `http://localhost:5173`).
